# 🎯 Habit Tracker

A beautiful and intuitive web application to track your daily habits and build positive routines.

## Features

✨ **Core Features:**
- ➕ Add unlimited habits to track
- ✅ Mark habits as completed each day
- 🔥 Track your streak (consecutive days completed)
- 📊 View total completed days for each habit
- 🎯 Real-time completion rate statistics
- 🔍 Filter habits (All, Completed, Pending)
- 🗑️ Delete habits you no longer need
- 💾 Persistent storage using browser's local storage

## How to Use

1. **Add a Habit**: Enter your habit name in the input field and click "+ Add Habit" or press Enter
2. **Track Completion**: Check the checkbox next to a habit to mark it as completed for today
3. **View Stats**: Monitor your total habits, completion rate, and daily progress
4. **Filter**: Use filter buttons to view all habits, only completed ones, or pending ones
5. **Delete**: Click the trash icon to remove a habit

## Features Explained

### Streaks 🔥
- Your streak shows how many consecutive days you've completed a habit
- Missing a day resets your streak count
- Keep the fire alive! 🔥

### Completion Rate 📊
- Shows the percentage of habits completed today
- Helps you stay motivated and consistent

### Progress Bar
- Visual representation of your habit's completion ratio
- Grows as you complete more days

### Persistent Storage 💾
- All your habits are automatically saved to your browser
- Your data persists even after closing the browser
- No account needed!

## Technology Stack

- **HTML5**: Structure and semantic markup
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **JavaScript**: Dynamic functionality and local storage management
- **Local Storage API**: Client-side data persistence
